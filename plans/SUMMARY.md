## 📋 WHAT WE'RE BUILDING

A unified automation platform with three flexible layers that turns every customer interaction into an opportunity for Bulgarian small and medium businesses.

### Core Offering
```
LAYER 1: AUTOMATION (Required foundation)
├─ Captures inquiries from all channels
├─ Responds instantly (24/7)
├─ Qualifies leads automatically
├─ Schedules appointments
├─ Follows up intelligently

LAYER 2: CMS (Modern website, no code)
├─ Drag-and-drop website builder
├─ 30+ Bulgarian-focused templates
├─ Fully integrated Automation Layer
├─ Hosting & SSL included
├─ SEO optimized

LAYER 3: CODE (Custom development)
├─ Modern tech stack (Next.js, Node, React)
├─ Full API access to Automation Layer
├─ Custom workflows & integrations
├─ Developer-friendly
├─ Enterprise-ready
```
